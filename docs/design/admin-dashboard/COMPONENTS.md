# Admin components (as used in the approved pages)

Shell: environment strip (34px), header with six-item nav, user menu, search. Containers: card (surface, 1px edge, radius 12 to 16), panel, drawer, dialog, menu. Data: table with sticky header and row actions, stat tile, sparkline/bar/line chart, severity badge, status pill, progress bar, timeline, audit row with before/after diff. Inputs: text, select, segmented control, switch (role=switch), checkbox, radio, search, date range. Feedback: toast, inline error, empty state, skeleton, degraded banner, permission-denied panel, read-only banner. Specs (sizes, colours, radii) are the values in `../brand/tokens/admin.tokens.*`; interactive behaviour is in the page files.

A separate per-component specification sheet (anatomy, variants, spacing annotations) has **not** been produced. Listed as missing.
